# 아버지의 홀인원 기념관 — 정적 버전

설치와 빌드가 전혀 필요 없는 HTML·CSS·JavaScript 프로젝트입니다.

갤러리 이미지를 클릭하면 큰 사진 모달이 열립니다. 배경, 닫기 버튼 또는 `Esc` 키로 닫을 수 있습니다.

## 바로 확인하기

`index.html` 파일을 더블클릭해서 브라우저로 엽니다.

## 내용 수정

`js/content.js`에서 날짜, 장소, 홀, 거리, 사용 클럽, 이야기, 축하 메시지를 수정합니다.

## 사진 교체

다음 파일을 같은 이름으로 교체하면 됩니다.

- `images/hero/hole-in-one-hero.png`
- `images/gallery/golf-course.png`
- `images/gallery/golf-ball.png`

## GitHub Pages 배포

1. GitHub에서 빈 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 올립니다.
3. 저장소 `Settings → Pages`로 이동합니다.
4. Source를 `Deploy from a branch`로 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.

이후에는 VS Code에서 수정하고 `git push`하면 자동으로 반영됩니다.
